📖 Nova v0.4 Commands

say - print text or a value
name = "Alex" - create a variable
age = 14 - create a number variable
score = score + 10 - change a variable
# comment - add a comment
if - check a condition
elseif - check another condition
else - run when previous conditions fail
end - finish an if block

Comparisons: == != > < >= <=
Math: +
