💡 Tips

🗣️ Use straight quotes Nova uses normal keyboard quotes like:
say "Hello"
Not curly quotes:
say “Hello”
🔚 Remember your end Every if block needs an end.
if age >= 13 say "Teen" end
📦 Check variable names If you create score, make sure you don't accidentally write scroe.
🧠 Choose and/or carefully and means both conditions must be true.
or means at least one condition must be true.
➗ Don't divide by zero A number cannot be divided by 0.
🟢 Conditions need true/false results An if condition needs something Nova can evaluate as true or false.
🟣 Parentheses need a pair If you open (, make sure you close it with ).

📚 Nova v0.7 Commands

say "Hello" → prints text

name = "Alex" → creates a variable

age = 14 → creates a number

score = score + 10 → changes a variable

# comment → adds a comment

+ → addition

- → subtraction

* → multiplication

/ → division

% → remainder

== → equal

!= → not equal

> → greater than

< → less than

>= → greater than or equal

<= → less than or equal

and → both conditions

or → either condition

not → reverses true/false

true / false → Boolean values

if ... end → condition

elseif → another condition

else → everything else

🧪 Examples

1. Say
say "Hello, Nova!"
2. Variables
name = "Alex" age = 14 say name say age
3. Math
score = 20 + 10 say score
4. Remainder
result = 12 % 5 say result
5. If
age = 16 if age >= 13 say "Teenager" end
6. If / Else
age = 20 if age < 18 say "Minor" else say "Adult" end
7. Elseif
score = 85 if score >= 90 say "A" elseif score >= 80 say "B" else say "Keep practicing" end
8. And
age = 16 if age >= 13 and age <= 17 say "Teenager" end
9. Or
age = 16 if age < 13 or age > 17 say "Outside teen range" end
10. Not
score = 75 if not score == 100 say "Not perfect" end
11. Boolean
has_ticket = true if has_ticket == true say "You have a ticket" end
12. Parentheses
age = 16 has_ticket = true with_parent = false if (age >= 13 and has_ticket == true) or with_parent == true say "Allowed" end
13. Nested If
age = 16 score = 90 if age >= 13 if score >= 80 say "Great job" end end
14. Comments
# This is a comment score = 100 say score
15. Reassignment
score = 50 score = score + 25 say score
16. Helpful Errors
say “Hello”

Nova v0.7 will explain that curly quotes are not supported and show you how to fix them.
