Nova v0.2 Commands
say → prints something
variable = value → creates or changes a variable
if → checks a condition
end → ends an if block

== → equals
!= → not equal
> → greater than
< → less than
>= → greater than or equal
<= → less than or equal
Examples
1. Say something
say "Hello, world!" Prints text to the output.
2. Create a variable
name = "Alex" Creates a variable called name.
3. Use a variable
name = "Alex" say name Prints the value stored inside name.
4. Numbers
age = 14 say age Creates and prints a number.
5. Basic math
age = 14 say age + 1 Adds numbers together.
6. Change a variable
score = 67 score = score + 10 say score Variables can be changed using their existing value.
7. If statement
score = 67 if score >= 50 say "You passed!" end Runs the code inside the if only when the condition is true.
8. If with a false condition
score = 20 if score >= 50 say "You passed!" end Since the score is below 50, the message isn't printed.
9. Compare text
name = "Alex" if name == "Alex" say "Hello Alex!" end Checks whether two pieces of text are equal.
10. Compare numbers
age = 14 if age > 13 say "Age is greater than 13" end Checks whether one number is greater than another.
11. Multiple commands inside an if
score = 67 if score >= 50 say "You passed!" say "Great job!" end Multiple Nova commands can run inside the same condition.
12. Comments
# This is a comment say "Nova is working!" Lines beginning with # are ignored by Nova.
