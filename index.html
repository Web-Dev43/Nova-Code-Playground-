📖 Nova v0.6 Commands


        

            say
            

            Prints text, variables, or calculations.
            
say "Hello"
say 5 + 3

        


        

            Variables
            

            Store information in a name.
            
name = "Alex"
age = 14
say name

        


        

            Math
            

            Nova supports +, -, *, /, and %.
            
x = 20
say x + 5
say x - 5
say x * 2
say x / 4
say x % 3

        


        

            Conditions
            

            Use if, elseif, else, and end.
            
score = 80

if score >= 70
    say "Passed"
else
    say "Try again"
end

        


        

            Comparisons
            

            Use ==, !=, >, <, >=, and <=.
        


        

            Boolean Logic
            

            Use and, or, and not.
            
age = 14

if age >= 13 and age <= 17
    say "Teen"
end

        


        

            Boolean Values
            

            Nova supports true and false.
            
has_ticket = true

if has_ticket == true
    say "You can enter"
end

        


        

            Comments
            

            Lines beginning with # are ignored.
            
# This is a comment
say "Hello"

9. If / Elseif / Else

if score >= 90
    say "Excellent"
elseif score >= 70
