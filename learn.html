📚 Nova Learn

Learn how to code with Nova

📦 Variables

Variables let you store information so you can use it later. 

name = "Alex"
age = 14

say name
say age

You can also change a variable: 

score = 50
score = score + 10

say score

🔢 Numbers & Math

Nova can work with numbers and addition. 

score = 90

score = score + 5

say score

The output is: 

95

🔀 Conditions

Conditions let Nova choose what code should run. 

score = 85

if score >= 90
    say "A"
elseif score >= 80
    say "B"
else
    say "F"
end

Nova checks the conditions from top to bottom. The first condition that is true gets executed.

💬 Comments

Comments are notes for humans. Nova ignores them when the program runs. 

# This is a comment

say "Hello!"

📢 Say

The say command prints something to the output. 

say "Hello Nova!"

You can also say the value of a variable: 

name = "Nova"

say name
