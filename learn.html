📚 Nova Learn

📦 Variables

A variable is a name that stores something. 

name = "Alex"
age = 14

say name
say age

🧮 Math

Nova can do five basic math operations:

+  addition
-  subtraction
*  multiplication
/  division
%  remainder
x = 12

say x + 3
say x - 3
say x * 3
say x / 3
say x % 3
Quiz: What is 12 % 4?


🔀 Conditions

Conditions let Nova make decisions. 

score = 80

if score >= 70
    say "Passed"
else
    say "Try again"
end

Nova checks the condition. If it is true, it runs the code inside.

You can also use elseif when you have another possibility. 

score = 85

if score >= 90
    say "Excellent"
elseif score >= 70
    say "Passed"
else
    say "Try again"
end
Quiz: If score = 50, will score >= 70 be true?


🧠 Boolean Logic

Boolean logic helps Nova answer questions with true or false.

and

Both conditions must be true. 

age = 14

if age >= 13 and age <= 17
    say "Teen"
end

14 is at least 13 AND at most 17, so Nova runs the code.

or

At least one condition must be true. 

age = 20

if age < 13 or age > 18
    say "Not a teenager"
end

not

not flips true to false, or false to true. 

score = 75

if not score == 100
    say "Not perfect"
end

🔗 Combining them

You can combine conditions using parentheses. 

age = 14
has_ticket = false
with_parent = true

if (age >= 13 and has_ticket == true) or with_parent == true
    say "You can enter"
end

True and False

Nova also understands the values true and false. 

has_ticket = true

if has_ticket == true
    say "You can enter"
end

💬 Comments

Comments are notes for humans. Nova ignores them. 

# This is a comment
say "Hello Nova!"

📢 Say

say prints something to the output. 

say "Hello!"

x = 10
say x
say x + 5
